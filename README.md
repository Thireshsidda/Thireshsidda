### Data Scientist · Great Learning
`October 2025 — Present`

**Learner Attrition Prediction**  
Built an XGBoost risk-modelling system from behavioural, progress, payment, and support data. Combined model scores with SHAP explanations and GPT-4o to turn predictions into clear intervention guidance for program teams—helping mentors, targeted communication, and in-app support reach learners who need attention.

**Learner Support Agent**  
Engineered a production-oriented Agentic AI support system that understands query intent and routes each request to the right capability. The system uses tool calling for learner-specific data and RAG for course and policy knowledge, supported by layered memory, security guardrails, response verification, caching, monitoring, and evaluation for safe, personalised, and scalable assistance.

### Associate Data Scientist · Great Learning
`June 2024 — October 2025`

**AI Notebook Quality-Control System**  
Created an automated quality pipeline that runs course notebooks from a central repository, detects code and dependency failures, uses GPT-4o with web search to recommend fixes, and sends structured alerts to program owners. It shifted notebook assurance from reactive troubleshooting to proactive quality control, improving course reliability and the learner experience.

**MIT–Great Learning Programs Lead**  
Led curriculum redesign across DSML, NCAI, and AAIDSP programs by weaving Generative AI and Agentic AI into the core learning journey. Partnered with MIT faculty, developed recording assets, and coordinated faculty content delivery—keeping programs aligned with industry practice while supporting learner value and program growth.

### Jr Associate Data Scientist · Celebal Technologies
`June 2023 — April 2024`

**Sensor Fault Detection System**  
Owned an end-to-end fault-detection platform for a leading automotive client, designed to identify air-pressure system failures early and reduce unnecessary repairs in heavy-duty vehicles. Built the lifecycle across Kafka streaming, MongoDB, preprocessing, feature engineering, XGBoost, Docker, GitHub Actions, AWS ECR, and EC2.

**Azure OpenAI RAG Chatbot**  
Built an enterprise document intelligence solution for search and question answering across internal Azure-hosted content. Designed the pipeline with Azure Form Recognizer for extraction, Azure Cognitive Search for indexing and retrieval, and GPT-3.5 with GPT-4 Vision for grounded response generation—making multi-document knowledge easier to discover and use.
